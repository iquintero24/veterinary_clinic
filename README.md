# 🐾 Veterinary Clinic Management System  

A simple console-based application built in **C#** to manage patients (pets) in a veterinary clinic.  
This project is developed step by step, week by week, to practice programming concepts while simulating real-world scenarios.  

---

## 🎯 Project Goal  
To provide a basic system where users can:  
- 📝 Register patients with their information.  
- 📋 List all registered patients.  
- 🔎 Search patients by name.  
- ✅ Validate input data to avoid errors.  

---

## ⚙️ Technologies Used  
- **C# .NET SDK**  
- **.NET Console Application**  
- **Object-Oriented Programming (OOP)**  

---

## 🏗️ Current Features  
- `Patient` model with properties: `Id`, `Name`, `Age`, `Symptoms`.  
- `PatientService` to handle patient registration, listing, and searching.  
- Console menu with options to register, list, search, and exit.  
- Basic error handling using `try-catch`.  

---

## 🚀 Future Improvements  
Planned features include:
